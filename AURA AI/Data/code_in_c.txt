Here's a simple example of a C program that calculates the area and perimeter of a rectangle.

```c
#include <stdio.h>

// Function to calculate area
float calculate_area(float length, float width) {
    return length * width;
}

// Function to calculate perimeter
float calculate_perimeter(float length, float width) {
    return 2 * (length + width);
}

int main() {
    float length, width;

    // Input length and width
    printf("Enter the length of the rectangle: ");
    scanf("%f", &length);
    printf("Enter the width of the rectangle: ");
    scanf("%f", &width);

    // Calculate and print area and perimeter
    printf("Area: %.2f\n", calculate_area(length, width));
    printf("Perimeter: %.2f\n", calculate_perimeter(length, width));

    return 0;
}
```

This C program does the following:

1. Asks the user to input the length and width of a rectangle.
2. Calculates the area and perimeter using separate functions.
3. Prints the calculated area and perimeter.

To compile and run this code, you can use a C compiler like GCC. If you have GCC installed, you can save this code in a file named `rectangle.c`, then compile and run it using the following commands:

```bash
gcc rectangle.c -o rectangle
./rectangle
```
